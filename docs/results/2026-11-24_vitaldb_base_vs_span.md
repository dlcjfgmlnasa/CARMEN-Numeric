## 해석

1. **흩어진 값 복원(①)은 두 모델 모두 nearest 를 크게 앞선다.** 혈압은 오차가 절반(ART 2.4 vs 4.9),
   마취제 Ce 는 30–40% 작다. 기본 run 이 span run 보다 5–16% 낫다 — 그 과제만 학습했으니 당연.
2. **구간 채우기(②)는 span run 이 확실히 낫다.** 기본 대비 HR −10%, ART −7%, BIS −9%, FiO2 −23%,
   체온 −34%, 마취제 Ce −26%. 기본 run 은 HR·체온에서 nearest 보다 못했지만 span run 은 대부분
   필드에서 nearest 를 넘는다 → 공백을 다른 변수·긴 맥락으로 추론하는 능력이 생겼다.
3. **span run 은 sparse 한 신호에도 유리**: 범주형(static) 정확도 0.826 vs 0.812, lab K·lactate·Hct 도
   ①에서 더 좋다. 기본 run 은 학습 후반 범주형 정확도가 계속 떨어졌다(0.823 → 0.807) — static 행
   과적합 신호. span run 은 그렇지 않았다.
4. **검사 수치는 아직 nearest 를 못 이긴다.** 케이스당 수 회뿐이라 학습 신호가 적다(전체 9,603행).
5. span run 의 span-mask val loss 는 8,000 step(2.160)에서 최저였고 이후 소폭 상승(2.206). 지금은
   UniTTab-mask val loss 로만 best 를 고르므로 그 시점이 저장되지 않았다.

## 결론 · 다음 단계

* 재구성 과제만 보면 **trade-off**: 기본 = 짧은 보간에 강함, span = 공백 추론·sparse 신호에 강함.
  어느 쪽이 좋은 *표현*인지는 downstream 으로 가려야 한다.
* 다음: frozen encoder 위 linear probe — 수술 중 저혈압 예측(5분 뒤 MAP < 65), 수술 후 AKI,
  재원일수 — 로 두 체크포인트 비교.
* 수정: 예측 분포 중앙값 decode, span-mask val loss 기준 best 체크포인트 별도 저장, lab 행 가중.

## VitalDB 전체 평가 — SpO2·MAC 중앙값 decode (2026-11-25 KST)

`scripts/eval_ckpt.py --split all` 로 두 체크포인트(`unittab_base_v2` 18k, `unittab_base_span_v1`
20k)를 **6,388 케이스 전부**(겹치지 않는 128행 창 12,224개)에서 채점했다. train(5,108)/val(635)/
test(645)를 따로 평가한 뒤 합산. 점추정은 `POINT_DECODE` — **SpO2·MAC 만 예측 분포 중앙값**,
나머지는 기댓값(앞 절과 동일). GPU 가 모두 다른 세션에 할당돼 있어 CPU(4 스레드)로 돌렸다
(약 2시간). 결과: `runs/<run>/best.eval_all.json`.

### 전체 합산(6,388 케이스)과 train/held-out 차이

| | ① loss 기본 / span | ② loss 기본 / span | ② HR span run | ② ART span run | 범주형 정확도 기본 |
| --- | --: | --: | --: | --: | --: |
| train (학습에 쓴 환자) | 1.200 / 1.254 | 2.330 / **1.967** | 3.55 | 6.26 | 0.943 |
| val+test (처음 보는 환자) | 1.266 / 1.308 | 2.341 / 2.198 | 4.26 | 7.67 | 0.810 |
| 전체 합산 | 1.213 / 1.265 | 2.332 / 2.012 | 3.69 | 6.53 | 0.917 |

* 전체 합산은 80%가 train 환자라 **낙관적**이다. 성능 주장은 val+test 로 한다.
* span run 은 구간 채우기에서 train–held-out 차이가 크다(HR 3.55 vs 4.26, ART 6.26 vs 7.67). 기본
  run 은 거의 차이가 없다(HR 4.54 vs 4.61) → span 과제에서 학습 환자의 패턴을 일부 외웠다.
* 범주형(static 행) 정확도 0.943 vs 0.810 — 환자별 static 값을 외운 것. 같은 이유로 검사 수치도
  전체 합산에서는 nearest 를 이기는 것처럼 보이지만(Hct 2.76 vs 3.59) held-out 에서는 여전히 진다.
